# 高雄市立三民家商・技高國語文 3D 課程宇宙與自主學習地圖
### Sanmin Vocational High School • 3D Immersive Chinese Curriculum Expo & Self-Directed Learning Map

本專案依據 108 課綱與三民家商服裝科專業情境，融合**鍾宗憲教授三年階梯理論**（不變與變、由感性到知性）與**黃國珍閱讀理解三階提問架構**（擷取訊息 ➔ 統整解釋 ➔ 省思評鑑），建構全台首座結合 3D 虛擬殿堂、學生化身漫遊、導師跨域指導與歷代文人對話的沉浸式自主修業世界。

---

## 🌟 專案核心功能與架構

1. **五大文本殿堂 3D 宇宙 (`expo.html`)**：
   - **中央文化廣場**：感恩樹下凝聚全校課程總架構與自主學習意象。
   - **五大殿堂島嶼**：敘事文本殿堂、抒情文本殿堂、思辨文本殿堂、文化文本殿堂、應用設計文本殿堂。
   - **動態巡禮**：
     - **服三和 31 位同學化身**：真實姓名、個人服裝配件（皮尺、方眼尺、裁縫剪、布卡等）、專屬換裝工坊與自主修業定錨。
     - **服裝科專任教師・服三和班導師 王士倫老師**：駐足應用設計殿堂，給予立裁打版與文學收束專題指引。
     - **國文科召集人 黃一軒老師**：全島巡視與課程總體諮詢。
     - **16 位歷代文人名家**：陶淵明、蘇軾、李白等文人名家駐足專屬水榭石亭，提供跨時空文學對話與傳世造型考據。
   - **雙人跨角色互動對話**：主角視角錨定，點選其他同學、導師或作家觸發面對面對話與同儕學習互勉。
   - **精準展台導航**：指派前進課次後，人物沿路徑步向該課 3D 展台前定錨專注研習。
   - **課程工作室（Course Studio 5 大分頁）**：
     - 分頁 1：自學單元網頁（無縫內嵌 `lessons/{id}.html`）
     - 分頁 2：黃國珍三階提問闖關測驗（即時核對答案、累計自主修業學分）
     - 分頁 3：服裝科跨域筆記（設計師概念、三民家商情境實務與手札存檔）
     - 分頁 4：教學簡報（Google Slides 內嵌）
     - 分頁 5：課堂學習單與任務成果

2. **課程地圖總覽首頁 (`index.html`)**：
   - 2D 視覺化課綱架構、年段階梯分佈、文本分類篩選與快速搜尋入口。

3. **自主學習單元庫 (`lessons/`)**：
   - 完整 56 門高一至高三技高國語文課次之獨立自學單元網頁。

## 🚀 部署至 GitHub Pages 步驟

1. 建立 GitHub 儲存庫並推送專案代碼：
   ```bash
   git init
   git add .
   git commit -m "feat: 三民家商技高國語文 3D 課程地圖與自主學習系統"
   git branch -M main
   git remote add origin https://github.com/<您的GitHub帳號>/<儲存庫名稱>.git
   git push -u origin main
   ```
2. 開啟 GitHub Pages：
   - 進入該儲存庫的 **Settings** ➔ **Pages**。
   - 在 **Build and deployment** 來源選擇 **Deploy from a branch**。
   - Branch 選擇 `main` / `/(root)`，點擊 **Save**。
3. 部署完成後，即可透過專屬網址隨時瀏覽：
   - 2D 總覽首頁：`https://<您的GitHub帳號>.github.io/<儲存庫名稱>/index.html`
   - 3D 沉浸式宇宙：`https://<您的GitHub帳號>.github.io/<儲存庫名稱>/expo.html`
